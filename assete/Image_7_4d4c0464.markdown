## Brand & Style

This design system targets independent game developers, mobile studios, and technical platform administrators seeking an uncluttered, high-velocity distribution environment. The aesthetic is clean, modern, and rigorously structured—blending software-tool utility with professional publishing precision.

The visual direction emphasizes functional minimalism combined with high-density administrative ergonomics. The interface provides absolute clarity: dense data sets, binary statuses (approved, pending, rejected), file verifications, and cryptographic package metrics must read instantly without decorative distraction. 

Key attributes:
- **Authority & Trust**: Evoked through sharp layout boundaries, restrained color application, and prominent security gating cues.
- **Developer-Centric Clarity**: Fast, keyboard-accessible workflows, clear file states, zero visual fluff, and immediate visual hierarchy.
- **Engineered Calm**: Crisp white and cool slate foundations that direct total focus toward release health, manifest details, and live APK artifacts.

## Colors

The palette is engineered for a pure-light context, establishing contrast using neutral slates rather than heavy fills.

### Palette Architecture
- **Canvas & Surface**: 
  - Primary Canvas: `#FFFFFF`
  - Sub-Canvas / Shell Background: `#F8FAFC`
  - Muted Surface / Recessed Wells: `#F1F5F9`
- **Borders & Dividers**:
  - Structural Border: `#E2E8F0`
  - Subtle / Sub-divider: `#F1F5F9`
  - Interactive / Hover Border: `#CBD5E1`
- **Typography & Content**:
  - Primary Text: `#0F172A` (Slate 900)
  - Secondary / Supporting: `#475569` (Slate 600)
  - Tertiary / Placeholder: `#94A3B8` (Slate 400)
- **Primary Accent (Indigo/Violet)**:
  - Base: `#4F46E5`
  - Hover / Active: `#4338CA`
  - Soft Tint / Focus Ring: `#EEF2FF`
- **Functional Semantics**:
  - Success / Approved / Download: `#10B981` (Emerald 500), Soft Background `#ECFDF5`
  - Destructive / Rejected / Error: `#F43F5E` (Rose 500), Soft Background `#FFF1F2`
  - Warning / Under Review: `#F59E0B` (Amber 500), Soft Background `#FEF3C7`
  - Admin Shield / Locked: `#6366F1` (Indigo 500)

## Typography

The typography scale utilizes `Inter` for clean visual rendering across dense UI grids, complemented by `JetBrains Mono` for cryptographic checksums, package identities (e.g., `com.studio.game`), version tags, and byte manifests.

- Headings employ tight tracking (`-0.015em` to `-0.025em`) to maintain editorial authority and visual compactness.
- Body copy relies on strict tabular lining figures in tables and meta rows to keep numeric version codes and file sizes aligned.
- Monospace labels are uppercase-enabled only when conveying verified system statuses or security hash previews (`SHA-256`).

## Layout & Spacing

The layout follows a fluid-grid container pattern locked to a 1280px maximum content width for readability, with edge-to-edge utility headers.

- **Breakpoints**:
  - Desktop: `>= 1024px` (12 columns, 24px gutters, 32px canvas margins)
  - Tablet: `768px - 1023px` (8 columns, 16px gutters, 24px canvas margins)
  - Mobile: `< 768px` (4 columns, 16px gutters, 16px canvas margins)
- **Rhythm Rules**:
  - Card collections (Apps Tab) collapse from a 3-column desktop layout to 2-column tablet, and single-column full-width mobile cards.
  - The Admin Panel leverages persistent split panels on desktop: an operational queue (400px fixed) paired with a responsive inspection/review viewport.
  - Vertical spacing uses multiples of 8px (`0.5rem`, `1rem`, `1.5rem`, `2.5rem`), ensuring uniform alignment across form fields and dashboard tiles.

## Elevation & Depth

This design system rejects heavy drop shadows in favor of crisp boundary planes, architectural borders, and minimal, diffused ambient contact shadows.

- **Layer 0 (Canvas Base)**: `#F8FAFC`. Unshadowed, flat foundation.
- **Layer 1 (Card & Module Surface)**: `#FFFFFF` bound by a 1px border of `#E2E8F0`. Shadow: `0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
- **Layer 2 (Elevated State / Dropdowns / Hover)**: `#FFFFFF` with border `#CBD5E1`. Shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.06), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`.
- **Layer 3 (Modals / Review Drawers / Security Gates)**: `#FFFFFF` surrounded by `#E2E8F0` with backdrop shield `rgba(15, 23, 42, 0.45)` blurred at `4px`. Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.

## Shapes

The design system standardizes on level 2 roundedness (8px base radius), creating an interface that feels sharp, controlled, and distinctly modern without being overtly playful or blocky.

- **Standard Inputs, Badges, Buttons**: `0.5rem` (8px).
- **Cards & Data Wells**: `0.75rem` (12px) to provide structural softness against exterior frames.
- **Full Shell / Modals**: `1rem` (16px) for distinct structural containment.
- **System Badges & Avatar Anchors**: Fully circular (`9999px`) reserved strictly for user icons, release health indicators, and verification check marks.

## Components

### Buttons
- **Primary**: Solid `#4F46E5` background, `#FFFFFF` text. Hover: `#4338CA`. Active: scale `0.99`. Subtle inset top highlight `rgba(255,255,255,0.15)`. Focus: ring 2px `#4F46E5` with 2px white offset.
- **Secondary / Outline**: `#FFFFFF` background, `#0F172A` text, 1px border `#E2E8F0`. Hover: `#F8FAFC` background with border `#CBD5E1`.
- **Action Emerald (Direct Download / Approve)**: `#10B981` background, `#FFFFFF` text. Hover: `#059669`.
- **Destructive Rose (Reject / Delete APK)**: `#FFF1F2` background, `#E11D48` text, 1px border `#FECDD3`. Hover: `#F43F5E` background, `#FFFFFF` text.

### Badges & Status Chips
- Height: 24px, radius: 9999px, padding: `0 8px`. Typography: `label-sm` (`JetBrains Mono` or `Inter` Medium).
- **Approved / Ready**: Background `#ECFDF5`, text `#047857`, 1px border `#A7F3D0`.
- **Pending Review**: Background `#FEF3C7`, text `#B45309`, 1px border `#FDE68A`.
- **Rejected / Quarantined**: Background `#FFF1F2`, text `#BE123C`, 1px border `#FECDD3`.

### Navigation & Tab System
- Border-bottom segmented line container `#E2E8F0`.
- Tab button with active state featuring a bottom highlight indicator in `#4F46E5` (2px height), bold text `#0F172A`, and an administrative lock badge next to the "Panel" label.

### Form Inputs & File Dropzone
- **Input Fields**: Crisp `#FFFFFF` surface, border 1px `#E2E8F0`, padding 10px 14px, typography `body-md`. Focus: `#4F46E5` border with `0 0 0 3px #EEF2FF` focus ring.
- **APK Dropzone (Add Apps Tab)**: 2px dashed `#CBD5E1` border on `#F8FAFC` background. Dynamic hover state changes border to `#4F46E5` and background to `#EEF2FF`. Displays file validation metadata (max 500MB, `.apk` signature scan).

### App Cards & Game Library Rows
- Solid `#FFFFFF` fill, 1px `#E2E8F0` border.
- Layout: Top header displaying game icon (64px, 12px radius, `#F1F5F9` placeholder), title, package ID (`code-xs`), followed by file size pill, version tag (`v1.4.2`), and primary emerald download trigger.
- Interactive hover: Border color elevates to `#CBD5E1` with layer 2 elevation lift.

### Security Gates & Review Modal
- **Security Gate (Panel Tab)**: Centered authentication card on `#F8FAFC`, featuring an indigo lock icon, PIN/Passcode masked entry, and inline validation with simulated lockout states.
- **Admin Review Modal**: Split-pane layout containing game screenshots/info on the left and technical APK analysis (permissions list, SHA checksum, SDK targets) on the right, terminating in primary Approve (Emerald) and Reject (Rose) action strips.

### Empty States
- Clean vertical stack: Minimalist linear slate wire icon (48px), `headline-sm` heading in `#0F172A`, helper text in `#475569`, terminating in a single primary action button to route to "Add Apps".
